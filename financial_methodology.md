# Metodologi Finansial

Pendapatan = pendapatan listrik + biaya layanan pengolahan sampah + pendapatan lain.
OPEX = OPEX tetap + biaya variabel per kg bahan layak × kg bahan layak per tahun.
Laba operasi = pendapatan − OPEX.
NPV = −CAPEX + jumlah arus kas operasi tahunan yang didiskontokan.
IRR dihitung numerik untuk arus kas konvensional.
Payback sederhana = CAPEX / laba operasi tahunan jika laba operasi positif.

BEP pendapatan operasional minimum untuk menutup OPEX tidak sama dengan BEP investasi penuh. Model belum memperhitungkan pajak, bunga, modal kerja, depresiasi, penggantian aset, dan nilai residu.
